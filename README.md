# ProofKit

ProofKit is a focused approval workspace for freelancers and small agencies. The MVP lets a team create an approval request, attach evidence, record a decision, and copy an audit receipt.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## MVP boundary

This prototype is local-only. Auth, shared review links, storage, payments, and production customer data are intentionally deferred until five target-user conversations validate the workflow.
